# Zomato_Data_Analysis_Project

Zomato Data Analysis | Python • Pandas • Matplotlib • Seaborn 


## 📌 Overview

This project analyzes Zomato restaurant data to uncover insights about customer preferences, pricing trends, and restaurant ratings. Using Python and data visualization libraries, the project focuses on exploring patterns that influence food choices and business performance.

---

## 🎯 Objectives

* Analyze restaurant ratings and pricing trends
* Identify popular cuisines and locations
* Explore the relationship between cost and ratings
* Visualize insights using charts and graphs

---

## 🛠️ Tools & Technologies

* Python 🐍
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Data Analysis Workflow

1. **Data Cleaning**

   * Handling missing values
   * Removing duplicates
   * Converting data types

2. **Exploratory Data Analysis (EDA)**

   * Distribution of ratings
   * Cost for two analysis
   * Cuisine popularity
   * Location-based insights

3. **Data Visualization**

   * Histogram of ratings
   * Count plots for cuisines
   * Scatter plot (cost vs rating)
   * Heatmap for correlations

* ⭐ Rating Distribution (Histogram)

## 🔍 Key Insights

* Higher-priced restaurants do not always guarantee higher ratings
* Certain cuisines are more popular in specific locations
* Most restaurants fall within a mid-range pricing category
* Ratings are influenced by multiple factors like cost and service
